# 版本说明

## Tg Netdisk 0.1.5

设置页「常规」增加上传并发数，范围 1～10、默认 4，保存后跨重启恢复。保持每块 512 KiB、同一 Telegram 连接内并发；视频、照片、缩略图和封面在每个文件开始时读取最新设置，当前文件保持原并发数。上传诊断显示保存后的配置。

常规设置保存不再重连 Telegram，上传中也可以调整；连接参数实际变化时仍要求当前任务结束。旧版配置缺少字段时自动使用 4。安装包位于 `release/0.1.5`。

## Tg Netdisk 0.1.4

代理输入改为明文并回显已保存值；账号页新增“上传诊断”。修复未携带 cryptg 导致纯 Python 加密慢的问题，改用 512 KiB、最多 4 个并行分块，进度写库移出网络确认路径。新增原生加速打包校验、脱敏上传耗时 / ACK 延迟日志和服务器等待识别。

原始加密路径实测约 0.22–0.36 MiB/s，启用 cryptg 后本机加密计算约 467–478 MiB/s；该数字不等同实际网络上传速度。详见 [性能排查报告](upload-performance.md)。安装包位于 `release/0.1.4`。

## Tg Netdisk 0.1.3

任务队列增加剩余时间：根据最近 8 秒的上传字节计算速度，在至少 3 个样本、跨度 2 秒后给出估算。速度不稳定、数据过期、排队、重试和发布阶段显示对应状态，不伪造整个发布流程的完成时间。每次重试重新估算；照片派生图使用实际上传大小。

历史记录的列表与详情均可删除本地记录，并在一个事务中清理任务项、消息映射和事件。保留媒体原文件、草稿与 Telegram 消息，活动任务无法删除；待确认记录删除时明确提示核对信息将丢失。删除与取消 / 重试 / 核对、任务启动互斥，避免并发状态错误。

36 项后端测试、8 项前端测试和队列 / 历史桌面检查通过。检查使用项目 `.runtime` 内的模拟任务，不发送或删除 Telegram 内容。安装包位于 `release/0.1.3`。

## Tg Netdisk 0.1.2

新建发布页顶部增加“重置”按钮。清空当前草稿的素材列表、封面、标题、简介和标签，恢复默认频道、标题加粗和本地来源，立即保存初始状态；保留登录、连接设置、原始文件、已入队快照和历史。停止当前草稿的媒体分析与未完成下载，忽略重置前尚未返回的导入 / 截图结果，避免旧素材再次填回页面。

验证：6 项前端测试通过，覆盖默认频道恢复、发布快照保护、旧保存与重置的顺序、迟到错误隔离；重置专项桌面检查覆盖页面初始化、重启恢复、原文件保留和迟到下载取消。产物位于 `release/0.1.2`。

## Tg Netdisk 0.1.1

修复所有应用内弹框显示在左上角的问题。弹框每次打开默认居中，支持拖动标题栏移动，拖动和窗口缩放时保持在可见范围内。保留关闭按钮、Esc、背景关闭与键盘焦点约束，并为每个弹框生成独立的可访问标题标识。

验证：类型检查、生产构建和桌面弹框专项检查通过，覆盖普通 / 宽弹框、重新打开居中、标题栏拖动、边界限制、缩放、表单编辑与关闭。

本次修复包位于 `release/0.1.1/Tg Netdisk Setup 0.1.1.exe`，可运行目录为 `release/0.1.1/win-unpacked`。旧版构建保留。

## Tg Netdisk 0.1.0

构建日期：2026-10-27；目标：Windows x64；需求版本：v1.5。

本版本提供 Electron 桌面客户端、Vue 媒体工作台和本机 Python 服务，包括扫码 / 2FA 及会话、频道与代理配置、本地 / 直链导入、Mediabunny 能力检测与逐帧截图、封面和混合相册、排序与草稿、单任务队列、取消 / 安全重试 / 待确认、历史、主题、缓存清理与日志。已打包依赖并锁定前后端版本。

自动化：20 项 Python 业务 / API / 协议测试与 3 项前端测试通过，类型检查、构建、Ruff、mypy 和依赖审计通过。本机短样本覆盖 MP4、MOV、MKV、WebM、旋转和可变帧率；桌面退出前保存、重启恢复及后台子进程释放通过。

安装包未签名；初次使用需填写本人的 API ID / API Hash 并扫码。真实 Telegram 登录、私人频道发送、封面最终显示、可点击标签、代表性大文件和干净 Windows 安装仍需按 [验证记录](verification.md) 联调。普通自动化测试不发布内容。

安装包位于 `release/Tg Netdisk Setup 0.1.0.exe`；可运行目录为 `release/win-unpacked`。用户数据在安装目录之外，升级 / 卸载默认保留。
