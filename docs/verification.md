## 0.1.4 代理明文与上传性能

确认同账号 / 节点 / 文件的对比条件，定位到原生加密缺失、串行小分块和上传回调等待 SQLite 三个本地瓶颈。原加密路径在本机仅约 0.22–0.36 MiB/s，加入 cryptg 后计算基准约 467–478 MiB/s；模拟 80ms ACK 的 4 MiB 文件，128 KiB 串行约 2.995 秒，4×512 KiB 管线约 0.202 秒。这些是计算和模拟基准，不等同真实 Telegram 上传测速。详细记录见 `upload-performance.md`。

48 项 Python 测试和 9 项前端测试通过，覆盖分块 / MD5 / 大文件 / 有界并发、取消与错误清理、进度非阻塞与排空、原生加密诊断、代理专用读取接口以及等待状态。账号页代理明文 / 保存回显、API Hash 仍隐藏和诊断页通过桌面检查，记录在 `.runtime/upload-settings-check`。

PyInstaller 构建已直接执行冻结后的后端并验证 cryptg 实际加载。实际线路吞吐仍待更新后用原文件复测；本次未发送真实频道内容，也未替换或复用正在运行的 Telegram 会话。
