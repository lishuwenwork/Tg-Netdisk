# Docker Web mode implementation plan

**Goal:** 在 `feat_支持web端` 增加 Docker / Linux Web 模式，仅选择服务器媒体文件，保留 master 原始桌面代码。

**Architecture:** 共用 Vue 媒体工作台、FastAPI、Telethon、SQLite 与任务队列。Web 模式由单个 Python 服务提供同源静态页面、API 和 WebSocket；Electron 运行模式保持独立。Web 登录使用 HttpOnly Cookie 与来源校验；服务器文件仅允许只读媒体根目录内的相对路径，截图和凭据写入独立数据卷。

**Tech Stack:** 原有 Vue 3 / TypeScript / Tailwind / Mediabunny / FastAPI / Telethon / SQLAlchemy，新增 cryptography、Docker Compose，可选 Caddy HTTPS。

## 步骤

1. 新增 `core/web_security.py`、Web 配置和加密凭据存储；验证登录、Cookie、CSRF、限流、退出与重启失效。
2. 新增 `services/server_files.py`、目录分页 / 搜索 / 多选注册 API；验证路径穿越、绝对路径、符号链接逃逸、媒体内容和原文件保护。
3. 在 `api/app.py` 按运行模式装配认证、路由和静态资源；Web 禁用任意路径注册和 URL 下载入口，受控媒体 Range 继续复用。
4. 新增 Linux Web 入口，配置固定容器端口、单实例与 SIGTERM 清理，保留发布中断 unknown 规则。
5. 前端新增 Web 访问登录与服务器文件选择器；API 改同源 Cookie / WSS，服务启动不依赖 Electron；相册和封面均使用服务器文件选择器；隐藏仅桌面可用的设置。
6. Docker 多阶段构建、只读媒体挂载、数据卷、凭据 secret 文件、健康检查及可选 HTTPS 代理；不安装浏览器、Electron 或视频转码工具。
7. 运行原有测试、Web API 与浏览器回归，补充容器构建检查（本机 Docker 不可用时明确标记未验证），记录部署与恢复操作。

## 验收重点

- 未登录无法访问业务 API / 媒体 / WebSocket，跨站写请求被拒绝。
- Web 只能浏览指定服务器目录，选择电脑文件和拖入均无效；不会提供本机上传或直链添加入口。
- 预览、分析、截图、封面、排序、草稿、任务、历史和代理配置可用；素材落盘入队后关闭浏览器不影响任务。
- 容器重启保留数据库、Telegram 会话和加密凭据；旧浏览器会话失效；publishing 恢复为 unknown。
- Windows 桌面模式及原有测试保持通过。
